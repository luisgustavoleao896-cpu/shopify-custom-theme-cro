# Shopify Custom Theme – CRO & Performance

Tema Shopify customizado desenvolvido para demonstrar:

- Domínio de Shopify Liquid
- Criação de Sections e Snippets reutilizáveis
- Estrutura modular de templates
- Implementação de upsell no carrinho
- Foco em performance (lazy loading)
- Organização seguindo boas práticas
